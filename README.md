> **Pando** (*from Latin: "I spread" or "I expand"*): Named after the world's largest living organism—a clonal colony of 47,000 aspen trees sharing a single underground root system. Pando maps and connects every emerging startup sprout across the global ecosystem long before it becomes visible on the surface.

---

## 🚀 Key Features

- **📡 Live Signal Radar**: Real-time ticker monitoring GitHub velocity spikes (+300% star/commit growth), YC batch directory launches, Product Hunt toppers, and stealth domain registrations.
- **⚡ Dual Pipeline View**:
  - **Kanban Board**: Drag-and-drop workflow across 5 stages (*Sprouted* ➔ *Root Enriched* ➔ *Thesis Matched* ➔ *Partner Review* ➔ *Term Sheet*).
  - **Dense Spreadsheet Table**: High-density table with fast filtering, sector sorting, and instant inspect drawers.
- **🎯 Interactive Thesis Engine**: Custom VC thesis configurator with criteria sliders (Team, Market, Traction, Tech Moat), sector rules, and red flag exclusions.
- **⌘K Raycast Command Bar**: Instant global search across all tracked startups, sectors, tech stacks, and AI actions.
- **📄 Investment Memo Studio**: One-click AI generation of IC briefs, market TAM breakdowns, founder backgrounds, and diligence risk questions (exportable to PDF & Markdown).

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, React 19, TypeScript)
- **Styling**: Tailwind CSS, Geist & Geist Mono Typography, Glassmorphic Dark UI
- **Components & Icons**: Lucide React Icons, Radix UI Primitives, `cmdk` Command Menu
- **Charts & Data**: Recharts, Framer Motion
- **Deployment**: Vercel & GitHub Actions

## 💻 Quick Start (Local Development)

```bash
# 1. Clone the repository
git clone https://github.com/your-username/pando-vc.git
cd pando-vc

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
